# 자료구조및실습

강원대학교 자료구조및실습 수업에서 학습한 개념과 C언어 실습·과제 코드를 정리한 저장소입니다.

C언어 기초를 바탕으로 배열·연결 리스트·스택·큐·트리 등의 자료구조를 학습했습니다. 데이터를 저장하는 방식과 삽입·삭제·탐색 과정이 자료구조에 따라 어떻게 달라지는지 코드로 확인했습니다.

## 학습 내용

| 주제 | 주요 내용 |
| --- | --- |
| 배열과 포인터 | 배열 접근, 주소와 역참조, 포인터를 활용한 데이터 처리 |
| 구조체와 동적 메모리 | 구조체 기반 데이터 표현과 메모리 할당·해제 |
| 순차 리스트 | 배열 기반 데이터 저장 및 삽입·삭제 시 원소 이동 |
| 연결 리스트 | 노드 구성과 링크 변경을 통한 삽입·삭제 |
| 스택 | LIFO 구조와 push·pop 연산 |
| 큐 | FIFO 구조와 enqueue·dequeue 연산 |
| 트리 | 계층적 데이터 구조와 노드 간 연결 관계 |
| 재귀호출 | 종료 조건과 재귀 호출의 처리 흐름 |

## 저장소 구성

- 수업에서 다룬 예제와 실습 코드
- 자료구조 구현 및 연산 관련 과제 코드
- 개념과 코드 동작을 정리한 학습 기록

수업 예제와 직접 작성·수정한 코드가 함께 포함되어 있습니다. 자료구조별 동작을 이해하고 구현 과정을 복습하기 위한 목적으로 정리했습니다.

## 사용 언어 및 환경

- 언어: C
- 환경: 수업 실습 및 과제별 개발 환경

## 학습한 점

자료구조의 정의뿐 아니라 연산 과정에서 데이터와 포인터가 어떻게 바뀌는지 이해하는 데 집중했습니다.

순차 리스트에서는 삽입·삭제 위치에 따른 원소 이동을, 연결 리스트에서는 노드의 연결과 메모리 해제 순서를 확인했습니다. 스택과 큐는 데이터가 들어오고 나가는 순서를 비교하며 각 구조의 차이를 익혔습니다.

코드를 읽을 때 변수값과 노드 간 연결 관계를 함께 따라가며, 연산 전후의 상태 변화를 설명하는 연습을 했습니다.
